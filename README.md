# 📊 Data Analyst Portfolio

> **Exploratory Data Analysis · A/B Testing · Data Visualization**

Data analysis projects in Python: cleaning real-world data, exploring it visually and turning it into clear answers. Each project folder has its own README with the question, method and key findings.

---

## 🗂️ Projects

| Project | Question | Methods |
|---|---|---|
| [🛒 Retail Customer Analytics (Complete Journey)](Retail-Customer-Analytics-Complete-Journey) | Which households grow or shrink, do campaigns work, and how do income and children change spending? | Segmentation, Difference-in-Differences, Welch's t-test |
| [⚽ World Cup Sports Shop: Churn Prediction](WM-Sportartikel-Churn-Prediction) | Which customers keep buying after the World Cup, and which threshold maximizes profit? | Classification, cost matrix, threshold optimization |
| [🐱 Mobile Games A/B Testing](Mobile-Gmaes-AB-Testing-with-Cookie-Cats) | Should the first gate in Cookie Cats move from level 30 to 40? | A/B testing, bootstrapping |
| [📱 Android App Market](The%20Android-App-Market-on-Google-Play) | What makes apps succeed on Google Play? | Data cleaning, market analysis, review sentiment |
| [🏠 House Price EDA](House-price-EDA) | What drives house sale prices? | Descriptive statistics, seaborn visualizations |
| [⚽ FIFA 21 Player Analysis](FIFA-21-EDA) | How do age, club and nationality relate to player ratings? | EDA, Plotly choropleth maps |
| [🎬 Netflix Movies](Investigating-Netflix-Movies-and-Guest-Stars-in-The-Office) | Are Netflix movies getting shorter? | EDA, confounder check by genre |
| [🏦 Which Debts Are Worth the Bank's Effort?](Which-Debts-Are-Worth-the-Bank's-Effort) | Does a more expensive debt recovery strategy pay off? | Regression discontinuity, hypothesis tests |
| [🏅 Nobel Prize Winners](A-Visual-History-of-Nobel-Prize-Winners) | Who wins the Nobel Prize, and how has that changed? | EDA, trends over time |
| [🏈 Super Bowl TV Data](Analyzing-TV-Data) | How are game results, viewers, ad costs and halftime shows connected? | EDA, regression plot |
| [🧑‍💻 GitHub History of Scala](The-GitHub-History-of-the-Scala-Language) | Who are the experts for a file in a large open-source project? | Data wrangling, time series |
| [🔎 Keywords for Google Ads](Generating-keywords-for-google-ads) | Which keywords fit a low-budget sofa campaign? | Keyword generation for SEM |
